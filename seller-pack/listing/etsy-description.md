# Trading Affiliate Website Template

A premium static website template for trading affiliates, introducing brokers, finance creators, and broker partner programme promoters.

Built with Vite, React, TypeScript, and clean responsive CSS. Includes editable affiliate link config, risk disclosure pages, broker programme explainer sections, platform cards, blog structure, SEO metadata, sitemap, robots file, JSON-LD, buyer setup docs, and seller support files.

This is not a trading bot. This is not financial advice. This is not an official Deriv website. It is a rebrandable website template/funnel system for affiliate marketers.

## Included

- Homepage
- How it works page
- Partner programme demo page
- Platforms page
- Learn page
- Blog index
- Long-form SEO article
- Risk disclosure page
- Contact/WhatsApp CTA page
- Config file for affiliate links
- Buyer documentation
- Listing and portfolio support files

No guaranteed earnings claims. No fake screenshots. No fake testimonials.
