# Start Here

Thank you for purchasing the Trading Affiliate Website Template.

This is a static website template for broker affiliates, introducing brokers, finance creators, and partner programme promoters. It is not a trading bot, not financial advice, and not an official Deriv website.

## First Steps

1. Open `src/config/affiliateConfig.ts`.
2. Replace all placeholder affiliate links.
3. Replace the brand name, owner name, WhatsApp number, and email.
4. Review every risk disclosure.
5. Run `npm install`.
6. Run `npm run build`.
7. Deploy the `dist` folder to GitHub Pages or another static host.

Do not publish the template with placeholder links.
